液态玻璃悬浮胶囊

始终浮于桌面的迷你专注胶囊，支持自由拖动与明暗自适应，内置 6px 拖拽防抖与签退二次确认，告别误点签退。

内置 LecDoc 秒开引擎

本地宿主代理静态前端资源，自动同步 LecSSO 会话与明暗主题，支持悬停预热文档树与零白屏切页。

原生 LecSSO 安全认证

基于系统钥匙串加密保存登录凭据，支持密码可见切换与两步验证（MFA），登录一次即可免登打通全线应用。

统一通知与公告回执

聚合工作室公告、云文档权限审批、考勤提醒与发版动态；队长可发布富文本公告并实时追踪已读状态。

三层本地缓存秒开

内存状态 + SQLite SWR 持久化缓存 + 卡面 CacheStorage，冷启动与切换标签页毫秒级呈现，后台静默刷新。

GitHub Releases 自动更新

应用内自动检测新版本、查看更新日志并实时展示下载进度，Windows 支持自动安装重启，macOS 一键打开安装镜像。
